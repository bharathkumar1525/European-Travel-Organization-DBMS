# European Travel Organization Database

##  Project Overview

The European Travel Organization Database is a MySQL-based relational database project designed to manage travel packages, customer bookings, hotels, tour guides, flights, and payments. It demonstrates database design concepts using primary keys, foreign keys, and relationships between multiple tables.

---

##  Features

- Database creation using MySQL
- 10 relational tables
- Primary Keys and Foreign Keys
- One-to-Many relationships
- Many-to-Many relationships
- Sample data for all tables
- SQL queries for data retrieval

---

##  Database Tables

- Countries
- Tour Packages
- Tour Guides
- Package Guides
- Customers
- Bookings
- Hotels
- Package Hotels
- Payments
- Flights
